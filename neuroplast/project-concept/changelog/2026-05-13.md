# 2026-05-13
#changelog

## Summary
- Fixed a Writing Studio regression where newly created scenes could flash open and then disappear because route remounts dropped the pending writing-route guard before debounced IndexedDB persistence finished.
- Moved the optimistic route guard and pending project write state in `workspace-root.tsx` above the component instance so chapter/scene creation remains stable across App Router remounts.
- Added guarded scene deletion in the Writing Studio navigator so scene rows expose delete controls only when a chapter has more than one scene, and active-scene deletion reroutes to a surviving scene.
- Added guarded chapter deletion in the Writing Studio navigator so chapter rows expose delete controls only when more than one chapter remains, and chapter/scene deletes now require confirmation prompts before removal.
- Added a first-class `Sociums` workspace surface with a required type dropdown plus richer organizational fields for leadership, territory, beliefs, allies, rivals, and continuity notes.
- Verified the fix with `npm run typecheck`, `npm run lint`, and `npm run build`.
