# 2026-05-11
#changelog

## Summary
- Fixed new-project creation so the workspace persists the project before navigating into its canonical writing route, preventing the brief flash back to the previously active project.
- Added a clearer explicit project switcher action in the shell/sidebar so moving between projects is easier to discover in both expanded and writing-focused layouts.
- Added direct per-project permanent deletion inside the trash view and standardized project action button sizing so lifecycle controls look and behave more uniformly.
- Tightened the sidebar `Switch project` / `New project` pair so the two primary project controls now render with matching flex sizing and breakpoint behavior.
- Corrected the sidebar project-action pair to stay vertically stacked while each button spans the available width, matching the intended layout instead of switching to a row.
- Added an explicit `Delete project` action in the main shell so the current project now has a visible delete path without first navigating into sidebar trash controls.
- Verified the change with `npm run typecheck`, `npm run lint`, and `npm run build`.
