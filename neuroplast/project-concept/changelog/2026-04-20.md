# 2026-04-20
#changelog

## Summary
- Tightened the left workspace sidebar with sharper radii, denser spacing, and firmer borders for a more compact product feel.
- Added a desktop expand/collapse control for the full sidebar and persisted the preference in local storage across reloads.
- Introduced a collapsed icon rail with project switching, new-project access, surface tooltips, and active-surface status affordances.
- Rebalanced the shell grid so the main workspace reclaims width when the sidebar is collapsed.
- Tightened the overall shell and shared workspace surfaces with sharper radii, calmer nested spacing, and more vertically stacked dense panels to improve professional polish.
- Reduced extra framing in the manuscript canvas and inspector so writing and CRUD-heavy surfaces retain more usable room.
- Added a follow-up wrap and overflow cleanup pass across the shell header, sidebar, manuscript panels, inspector cards, and reusable entity workspaces so long labels and metadata stay readable.
- Reworked the writing navigator into a compact chapter list plus active scene list and tightened manuscript/shell spacing so the draft gets more visual room.
- Refined the visual styling of the compact writing workspace so navigator states, support cards, and the editor shell feel more intentional and premium.
- Added shared selected-state contrast guardrails so active navigation and adjacent list-based workspace selections keep readable foreground text during future visual refinements.
- Reworked the scene navigator into a single hierarchical chapter-and-scene list with clamped titles and inline scene creation so the writing rail is easier to scan without hiding the inspector.
- Moved project-aggregate workspace writes onto an optimistic UI flow with short debounced background IndexedDB persistence so common interactions no longer wait on storage before updating visible state.
- Narrowed the TipTap scene-editor resync path so metadata and link changes do not force unnecessary document resets.
- Removed the heaviest blur treatment from the main shell panes to reduce paint-heavy compositing cost in production.
- Verified the changes with `npm run typecheck`, `npm run lint`, and `npm run build`.
