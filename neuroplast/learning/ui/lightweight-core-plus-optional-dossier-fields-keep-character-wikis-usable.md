# Lightweight Core Plus Optional Dossier Fields Keep Character Wikis Usable
#learning

## Insight
When a story-bible character surface needs wiki-style depth, a small required core plus optional dossier sections keeps the tool useful for both major and minor characters.

## Why It Matters
- Authors will avoid a character tool that demands a full biography for every incidental person.
- A structured core still gives continuity and filtering a reliable foundation.
- Optional dossier fields let the surface deepen over time without blocking early drafting.

## Reusable Practice
1. Make only the identity and active story-role fields required.
2. Keep deeper biography, voice, secret, and continuity notes optional but structured.
3. Model character relationships as typed records instead of burying them inside freeform notes.
