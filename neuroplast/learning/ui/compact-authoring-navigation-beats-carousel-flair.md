# Compact Authoring Navigation Beats Carousel Flair
#learning

## Insight
For writing tools, compact list-driven navigation usually beats carousel-style navigation. Authors need to scan chapter and scene structure quickly, and dense static lists support that better than motion-heavy patterns.

## Why It Matters
Carousels can feel modern, but they hide structure and consume interaction effort. In an authoring workflow, chapter and scene navigation is frequent enough that scan speed and predictable density matter more than visual flair.

## Reusable Practice
- Prefer compact chapter lists plus active-scene lists over rendering every structural branch at once.
- Reduce surrounding shell chrome before shrinking the primary editor surface.
- Keep structural creation actions contextual so authors add chapters globally and scenes from the active chapter scope.
- Tighten support-card density around the editor first; preserve comfortable prose spacing for the actual writing surface.
