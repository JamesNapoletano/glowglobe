# Manuscript-First Inspector Layout
#learning

## Insight
For writing tools, linked context becomes more usable when it lives in an adjacent inspector rather than in a competing main-column layout.

## Why It Matters
Writers need the manuscript to remain the visual center of gravity. If metadata, project creation, and reference previews all compete for center-column space, the workspace feels crowded and the draft loses priority.

## Reusable Practice
- Keep project and surface navigation in a stable left rail.
- Reserve the center pane for the active draft or selected primary workspace.
- Move scene metadata and linked entities into a right-side inspector tied to the active scene.
- Use lightweight overview states for adjacent surfaces before full CRUD workflows exist.
- Prefer modal entry for project creation when always-on creation UI crowds the main workspace.
